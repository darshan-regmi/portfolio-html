# Portfolio (HTML)

A personal portfolio website built with HTML, CSS, and Bootstrap. A static single-page site with smooth scroll navigation.

## Sections

- **Home** — Hero / landing
- **About** — Bio and background
- **Service** — Skills and services offered
- **Portfolio** — Project showcase
- **Contact** — Contact form / details

## Tech Stack

- **Frontend**: HTML5, CSS3
- **Framework**: Bootstrap
- **Fonts**: Google Fonts (Open Sans)
- **Animations**: Vanilla JavaScript scroll effects

## Running Locally

No build step required — open `index.html` in a browser, or serve with:

```bash
npx serve .
```
